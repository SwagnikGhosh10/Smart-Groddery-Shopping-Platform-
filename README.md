This is a Full Stack Grocery Shopping Platform .
Tech Stack Used : Node.js, Express.js ,Mongodb , React.js 
In this project i have built a full-stack e-commerce application suppoprting 40 + products across 10 categories ,with user cart  and order management .
Designed and implemented 15 REST API endpoints with Express.js handling CRUD operations,JWT based authentivation ,  and role based middleware.
Modeled and queried MongoDB collections for products,users,and orders ,optimized queries to keep average response time under 10 ms.
Build responsive React.js frontend and deployed via Vercel .
